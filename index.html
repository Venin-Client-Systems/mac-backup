Mac Backup

Mac Backup is a private Google Drive integration being configured for George Atkinson’s personal Mac. It is not a public backup service and does not offer accounts to other people.

The intended workflow uses the free, open-source tools restic and rclone to encrypt selected local backup data on the Mac before uploading it to a private application-data area in George’s Google Drive account.

Setup and recovery validation are in progress. This page does not certify that backups are active or that full Mac restoration has been demonstrated.

Google Drive access

The integration is configured to request access only to its own application-data area, using rclone’s drive.appfolder setting (Google’s drive.appdata scope). This scope does not provide access to unrelated My Drive files, email, contacts or calendars.

The Google authorization belongs to George’s own app registration. Backup data is transferred directly between the local software and Google Drive; this website does not receive backup files, access tokens or encryption passwords.
