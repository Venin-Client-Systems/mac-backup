Mac Backup privacy notice

Last updated: 18 September 2026

This notice describes the planned data handling of Mac Backup, George Atkinson’s private Google Drive integration. Setup and recovery validation remain in progress. It is not a service offered to the public.

Data accessed and purpose

The local backup tools read the Mac files selected for backup. Google authorization is limited to the integration’s own private application-data area through Google’s drive.appdata scope (rclone’s drive.appfolder setting). That access is used to create, list, read and manage encrypted backup repository objects, including restoring saved data and, when explicitly configured, removing expired backup history.

Storage and protection

The intended configuration encrypts file contents and file/snapshot metadata locally with restic before upload. Google Drive stores the resulting encrypted repository objects. Google can still observe service information such as object sizes, transfer times, storage usage and account activity. Local software stores its authorization configuration on the Mac with restricted file permissions. Encryption recovery credentials must be kept separately from the backup repository.

Sharing and other uses

The integration does not intentionally share backup contents with other people or sell data, use it for advertising, or use it to train AI models. Google processes stored objects and service information under its own applicable terms and privacy policies. No backup contents, credentials or authorization tokens are sent to this website.

Retention and control

Backup data remains in the account until George or an explicitly configured retention process deletes it. No automatic retention-deletion schedule has been enabled during setup. George can revoke the integration’s access through Google Account settings. Revoking access does not itself establish that stored backups have been deleted. Deleting the integration’s hidden application data can permanently destroy its backup repository. The separate encryption credential is necessary for restoration.

This website

These static pages contain no analytics scripts, advertising, forms, cookies set by page code, or embedded third-party assets. These pages are hosted on GitHub Pages. GitHub logs visitor IP addresses for security purposes; see the GitHub Privacy Statement.

Personal use and contact

George administers the integration through the Google Cloud project’s configured support contact. It accepts no public users. Questions about this personal integration can be directed through the support contact shown on its Google authorization screen.
